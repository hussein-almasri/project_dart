# Expense Tracker 💰

A simple console-based Expense Tracker application built with Dart.

This project is part of my journey learning Dart before moving to Flutter.

## 📌 About The Project

The Expense Tracker allows users to manage their daily expenses through a simple console application.

The project focuses on practicing Dart programming, Object-Oriented Programming, collections, enums, null safety, and other important Dart concepts.

## ✨ Features

- Add a new expense
- Remove an expense by ID
- Find an expense by ID
- Show all expenses
- Search expenses by title
- Case-insensitive search
- Filter expenses by category
- Calculate total expenses
- Calculate total expenses by category
- Count expenses
- Calculate average expense
- Remove all expenses
- Validate expense title
- Validate expense amount
- Handle empty expense lists

## 🗂️ Expense Categories

The application supports:

- Food
- Transport
- Shopping
- Bills
- Entertainment
- Health
- Other
